# 简历要点

## 中文

**千年桥韵｜中国古代桥梁交互式数据叙事｜独立开发**

- 独立完成 102 座古桥数据的故事化产品设计，从空间分布、历史演化、桥型格局和个案详情组织完整探索路径。
- 使用原生 JavaScript、Leaflet 与 ECharts 构建地图—时间轴—统计图表联动界面，实现朝代筛选、点位缩放和桥型专题交互。
- 设计历史主题视觉系统与响应式布局，并将静态站点接入 GitHub Actions 和 GitHub Pages 发布流程。

## English

- Designed an interactive cultural-data story across 102 ancient Chinese bridges, spanning spatial distribution, historical evolution, bridge typologies, and case studies.
- Built synchronized map, timeline, bar-chart, and Sankey views with vanilla JavaScript, Leaflet, and ECharts.
- Created a responsive editorial visual system and automated GitHub Pages deployment with GitHub Actions.
