# ancient-bridges-story
# 中国古桥梁可视化系统
Ancient Bridges Visualization System
---
## 项目简介
本项目以“中国古代桥梁”为主题，基于数据可视化技术构建交互式网页系统，从空间、时间与结构三个维度，对中国古桥梁的分布格局与发展演化进行综合展示。
通过地图、图表与动态叙事结合的方式，系统呈现桥梁与地理环境、材料选择及历史背景之间的关联关系，探索中国古代桥梁所体现的工程智慧与文化价值。
---
## 项目特点
* 📍 **空间可视化**：基于地图展示古桥梁的地理分布
* 📊 **统计分析**：桥型、材料与朝代分布图表
* 🕰 **历史演化**：按时间轴动态展示桥梁发展过程
* ⭐ **重点桥梁标识**：核心桥梁高亮展示与专题解读
* 📖 **个案叙事**：详情页提供结构、地域与文化分析
---

## 数据说明
桥梁数据以 JSON 格式存储，包含：
* 名称、朝代、类型
* 建材、位置
* 经纬度信息
数据来源于相关历史文献与研究资料整理。
